# M8: the GPU methods the title used

Measured on the owner's title, 600 presented frames (`NX_MAX_FRAMES=600 NX_TRACE_GPU=1
NX_GPU_TOP=0`). Aggregate counts only; the methods are the ones NVIDIA's open-gpu-doc class headers
name (`tools/gen_methods.sh` generates the tables). An array register is listed per element
(`NAME[i]`). Writes to `CALL_MME_MACRO` and `CALL_MME_DATA` are the macro calls (macros are listed
last). Three lists: the methods written by the method stream, the methods macros wrote (a macro's
writes are counted apart from the stream's), and the macros called.

See `M8-gpu-front.md` for what the numbers mean.
